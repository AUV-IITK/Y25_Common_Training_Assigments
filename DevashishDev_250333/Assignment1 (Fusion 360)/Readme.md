# Assignment 1

## Overview
This assignment was a basic Fusion 360 CAD training task focused on understanding how 2D sketches are converted into 3D models using extrusion and revolve features.
It was meant to strengthen fundamental CAD modelling skills through two simple part-design exercises.

## What was done
Two parts were modelled in Fusion 360 by following the given engineering drawings.
The first part used **linear extrusion**, where a closed sketch was extended to form a solid, and the second part used **revolve**, where a sketch profile was rotated about an axis to create a radially symmetric model.

## Questions
- **Part 1: Linear Extrusion** — Create the shown 3D part by drawing its 2D profile and extruding it to the required thickness.
- **Part 2: Revolved Extrusion** — Create the symmetric part by sketching its section and revolving it around a central axis.

## What was learnt
This assignment helped in learning the basics of sketch-based modelling, dimension checking, and using two important CAD tools: extrude and revolve.
It also gave practice in reading part drawings correctly and exporting final models as STEP files for submission.
